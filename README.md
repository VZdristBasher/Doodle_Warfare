# Doodle_Warfare
Моя цель создать полноценную игру в жанре beat-'em-up с комплексной комбо-системой и системой ввода, считывающее инпуты клавиш передвижения
Для достижения такой цели, конечно, требуется достаточный уровень квалификации в вопросах кодинга и знания программ разработки - соответственно,
данный проект это ничто иное как наработки отдельных систем и их комбинаций для того, чтобы потом их можно было реализовать в одной полноценной игре.

Doodle Warfare разрабатывается на движке Game Maker из-за простоты обращения с движком и простого синтаксиса собственного кода Game Maker Language
Для достиджения целей проекта в нём должно быть реализовано:
1. Проект должен запускаться
2. Примитивная система управления (Ходьба влево-вправо, прыжок)
3. Примитивная система атаки (создание хёртбокса, соответствующая реакция игры)
4. Автоматическое создание сущностей противников
5. Начисление очков при победе над противником
6. Примитивный искусственный интеллект для сущностей противников
7. Возможнсть проиграть

При достижении вышеописанных целей проект будет считаться завершенным и можно будет перейти ко следующему этапу разработки

Пока что рано планировать следующие шаги разработки, однако уже сейчас можно декларировать, что дальнейшая разработка будет вестись на другом
движке, в следствие оограниченности Game Maker, несмотря на удобство разработки и простоту интерфейса
